# v2.2.6（2026-10-30）

本轮主题：离线预览模式 + 驱动器参数页修正；首次把 2.1.4 以来未提交的工作推送 GitHub 并发布 Release。

## 离线预览：未连接可浏览所有界面

- 连接页入口按钮「跳过连接(仅本地 Blockly)」改名「离线预览(不连接机器人)」（`connect_page.dart`）。
- 主页四宫格导航去掉监控/维护的 `online ? ... : null` 门控（`main_home_page.dart`）。
- 维护页/文件配置页「驱动器参数设置」：未连接时跳过 `DriverTechModeGate` 诊断与 `enter()`，直接浏览打开驱动器参数页（`tool_page.dart` / `config_file_page.dart`）。
- 驱动器参数页 `_exitPage`：未连接时跳过 `gate.exit()` 退出 HTTP，直接返回，不再弹「退出失败」对话框（`driver_page.dart`）。
- 行为边界：在线门控完全不变（只在 `!isConnected` 分支生效）；离线时需要连接的操作仍提示「请先连接控制器」或失败，数据为空属预期。

## 驱动器参数页修正（承 2026-10-27 两轮）

- 中间/底部分隔条 `maxFrac` 0.72 → 0.92（`driver_page.dart`）。
- 左侧按钮列、底部工具栏、轴调试行加滚动兜底修 overflow（`widgets/driver_params_panel.dart`）。
- 「电流前馈」与「最大扭矩输出限制%」共用 key `current_forward` 导致联动的修正：`current_forward`（`paras[66]`）归位增益调整-1；安全设置-1 移除「最大扭矩输出限制%」（Android 参考中无独立接口 key，待固件提供）（`driver_params_defs.dart`）。

## 其他

- 修正 2026-06 以来失效的存量 `test/widget_test.dart`：首屏断言由 Blockly 页「领鹏智能编程」改为连接页「连接」「离线预览」按钮。
