
# v2.1.6

## 本轮目标

Windows 编程页顶栏「返回」位置不对；安卓是对的。只适配 Windows，不改安卓。

## 用户反馈 / 问题现象

1. 初轮：奶油槽里「← 返回」位置不对。
2. 复验截图：用户用红框标出应在**奶油槽上半、略靠左**（与标题一条线）。上一轮下移 7–11px 后按钮落在槽下沿，偏低偏右。

## 原因判断

奶油平行四边形上宽下窄，视觉中心在上半，不是整栏几何中心。整体 `Transform.translate` 下移过量。日志证据不足，依据用户红框截图。

## 实际修改

- 去掉 Windows 整体下移
- `_NeiyePageBackButton`：Windows `Alignment(0.45, -0.32)` 落到槽上半
- 右侧内收 16px
- 构建号 `2.1.6+6`

## 验证

- `flutter analyze lib/app/widgets/lp_robot_pose_bar.dart` 通过
- Windows 画面：**待用户对照红框确认**

## 结果

代码已改，**待用户实际验证**。
