## 后续轮次：Android 模拟器编程页巨大刷新图标（2026-09-15）

### 本轮目标

用户反馈模拟器经常在「领鹏智能编程」只看到放大模糊的橙色刷新图标。

### 用户反馈 / 问题现象

截图：顶栏正常（标题、AI、刷新、返回），工作区被 `bian-top-icon2-2` 刷新切图撑满。无本轮模拟器运行日志（日志证据不足）。

### 原因判断

- 已证实：该图形与顶栏刷新切图为同一张 PNG。
- 高概率：Android WebView 默认允许缩放 + 用 `Opacity` 隐藏 Virtual Display，模拟器上会把顶栏纹理错误合成到工作区。
- 初步推测：偶发 `innerHeight` 异常也会把 Blockly HTML 工具栏图标撑很大（已加尺寸上限）。

### 实际修改

- `lp_blockly_webview_visibility.dart`：关闭缩放、wide viewport、textZoom=100；Android 不再用 Opacity 藏 WebView
- `blockly_demo_page.dart`：顶栏切图固定 28px；加载前再次 `enableZoom(false)`
- `lp_robot_pose_bar.dart`：标题栏 Stack 裁剪
- `index.html` / `code.js`：禁止页面缩放；工具栏按钮最大 52px

### 验证

- `flutter test test/blockly_ai_append_test.dart test/blockly_ai_tool_loop_test.dart` 通过
- 模拟器画面：**待用户实际验证**（需完全重启，热重载不够）

### 结果

- 代码已改，问题 **待用户实际验证**
- 未在模拟器上复现确认

### 遗留事项

若重启后仍出现：改试 Hybrid Composition，并抓一份 `flutter run` 日志。

## 后续轮次：模拟器能选中块但不能拖动（2026-09-15）

### 本轮目标

用户反馈模拟器滚轮/鼠标选中积木后无法移动。

### 原因判断

- 高概率：Flutter 未把拖动手势交给 WebView（无 EagerGestureRecognizer），move 被父级吃掉。
- 高概率：Android 模拟器一次拖拽同时发 mouse* 与 touch*，Blockly 只认第一种 id，后续 move 被丢弃 → 只能点选。
- 日志证据不足（无模拟器运行日志）。

### 实际修改

- Android WebView：`EagerGestureRecognizer`
- `blockly/core/touch.js`：手势进行中把 mouse/touch 视为同一指针（仅 move/up）
- `code.js`：实现 `resetBlocklyDragState_`；Android 关闭滚轮缩放
- 构建号 `2.1.5+2`，迫使 Android 重新解压 Blockly

### 验证

- `flutter test test/blockly_ai_append_test.dart` 通过
- 模拟器拖块：**待用户实际验证**

### 结果

代码已改，**待用户实际验证**。
