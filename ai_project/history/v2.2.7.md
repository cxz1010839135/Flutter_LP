# v2.2.7

## 本轮目标

新增视觉机型首页分流：控制器上报型号以 `SJ` 开头时，连接成功后进入新的「视觉首页」骨架；其余型号与离线预览行为完全不变（用户要求：保持现有所有界面不变）。

## 基于版本

v2.2.6+8（`pubspec.yaml` 2.2.6+8 → 2.2.7+8，构建号保持 +8，未动 Blockly 资源）。

## 用户需求与确认

- 用户上传主页截图，红箭头指向底栏左侧机型名（如 `XYZ01`，即连接应答 `robot.model`），要求「通过新加型号用图一所指的这个做区分，让你去新的首页，那边是用视觉相关的」。
- 经确认：① 型号判定规则暂定 **以 `SJ` 开头**（用户原话「暂定SJ为前面的标志」）；② 新视觉首页本轮**先搭骨架**（同风格顶栏/四键/运行栏，主体为视觉功能占位区，后续再按设计填充）。

## 原因判断

- 机型名来源已证实：`HttpManager.connectAndApply` 从 connect 应答 `robot.model` 取值写入 `RobotState.robotModel`（[http_manager.dart](file:///d:/Adroid_ws/LpRobt_Flutter/Lpzn_windows/lib/network/http_manager.dart#L111-L129)）；主页底栏经 `LpRobotFootBar` 显示该值。
- Blockly 编程页在线返回用 `Navigator.pop`（无主页路由名依赖），分流后从视觉首页进入编程页可正常返回。

## 实际修改

1. [robot_state.dart](file:///d:/Adroid_ws/LpRobt_Flutter/Lpzn_windows/lib/core/robot_state.dart)：新增 `isVisionModel` getter —— `robotModel.trim().toUpperCase().startsWith('SJ')`，规则写明「暂定」。
2. [vision_home_page.dart](file:///d:/Adroid_ws/LpRobt_Flutter/Lpzn_windows/lib/features/home/vision_home_page.dart)（新增）：视觉首页骨架。
   - 布局与 `MainHomePage` 同风格：`LpRobotPoseBar` 顶栏（断开/返回登录）+ 左侧四键（操控/编程/监控/维护，复用主页切图 `HomeAssets`/`RobotPathLayout` 配置名）+ 右侧 `LpRobotRunSidebar` + 底部 `LpRobotFootBar`（显示 SJ 型号名）+ `LpStatusPanel`。
   - 中央视口为 `_VisionViewport` 视觉功能占位区（图标 + 「视觉功能区域」+ 当前机型提示）。
   - **「编程」按钮为占位提示**（用户确认：视觉后期引入专属编程界面，**不套用 Blockly**，就绪前弹「视觉编程界面建设中，敬请期待」，不进 Blockly；该长期事实已记入 `PROJECT.md` 设计约束）。
   - 各导航写 `视觉主页：` 前缀操作日志。
3. [connect_page.dart](file:///d:/Adroid_ws/LpRobt_Flutter/Lpzn_windows/lib/features/connect/connect_page.dart)：新增 `_openHomeByModel()`，连接成功后按 `isVisionModel` 分流；分流决策提为公开函数 `buildHomePageByModel()`；离线预览 `_openOfflineHome` 保持原主页不变（无型号，非视觉机型）。
4. [vision_home_routing_test.dart](file:///d:/Adroid_ws/LpRobt_Flutter/Lpzn_windows/test/vision_home_routing_test.dart)（新增，应用户要求补验证）：10 项测试覆盖分流逻辑。

未改动：`MainHomePage` 及所有既有页面、连接/轮询/遥测逻辑、Blockly 资源。

## 验证

- `dart run tool/sync_app_version.dart`：2.2.7+8 已同步生成文件。
- `flutter analyze`（本轮改动文件）：No issues found。
- `flutter test`：40/40 全部通过（原 30 + 新增 10）。分流测试覆盖：
  - `isVisionModel`：SJ01 / sj02（小写）/ SJ-100 / 带空格 → 视觉机型；XYZ01 / XSJ01（SJ 非开头）/ 空型号 → 非视觉机型；
  - `buildHomePageByModel`：SJ01 → `VisionHomePage`；XYZ01 → `MainHomePage`（现有主页不变）；空型号（离线预览）→ `MainHomePage`。
- 真机连接（SJ 型号 / XYZ01 实机）待用户实测。

## 结果

- **待用户实际验证**：
  1. 连接 SJ 开头型号（如 SJ01）→ 进入视觉首页（占位区显示机型名），编程按钮弹「建设中」提示，操控/监控/维护四键可正常进出；
  2. 连接非 SJ 型号（如 XYZ01）→ 仍进原主页，界面与改动前完全一致；
  3. 离线预览 → 仍进原主页。

## 遗留事项

- 视觉首页主体内容（相机画面、视觉检测流程等）待用户提供视觉方案/设计后填充。
- **视觉专属编程界面（不基于 Blockly）** 后期另行实现；就绪前视觉首页「编程」按钮保持占位提示。
- 「SJ 开头」为暂定规则；若正式型号命名确定（精确名/列表），只需改 `RobotState.isVisionModel` 一处。
- 视觉首页中央占位与左四键、右运行栏的取舍（是否保留运行栏）可在视觉方案确定时一并调整。
