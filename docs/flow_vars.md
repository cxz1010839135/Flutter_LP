# 流程变量约定（人工确认版）

> 运行时真源：`config/blockly_ai_flow_vars.json`（应用内由 AI 对话维护）。  
> 规则：未确认不得用于生成步进/门型程序；禁止套用其他工程默认寄存器。

## 用法（对话）

1. 发变量清单，例如：
   ```
   自动使能 M20
   运动完成 D9000=0
   取料点 P1
   步序 S10
   ```
2. Agent 整理后回复「确认」
3. 修改：`把 M20 改成 M16`（改后需再确认）
4. 查看：`查看变量` / 清空：`清空流程变量`

## 从 IO 表 Excel 导入

1. 对话发送「导入IO表」，或打开 AI 设置 →「导入 IO 表」
2. 选择 `DM注释_*.xlsx`（含 sheet「IO表」「本体IP100」）
3. 自动分配：`3#Xn/Yn`、`扩展#Xn/Yn`、公用 `Xn` → 本机 X/Y → M1000+/M2000+；`1#`/`2#` 仅注释
4. M 注释与分配结果写入流程变量（待确认）与 `config/blockly_ai_io_table.json`
5. 发送「从IO表生成」或设置里「生成到画布」→ 本体+扩展输入/输出映射函数

## 状态

应用内查看：AI 面板 → 设置 →「流程变量约定」/「IO 表 Excel」。
