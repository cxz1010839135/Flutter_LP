# 2026-09-03 变更详情（2.1.2）

## 背景

现场工控平板需要一眼看出当前走 Wi‑Fi 还是网线；操控页左右导航与点动距离格此前会同时高亮，改为整页单选。

## 一、连接页

- 已连 Wi‑Fi：标签为「当前连接WIFI：xxxx」（SSID）
- 网线 / 未连 Wi‑Fi：仍为「控制器IP」
- Windows：`netsh wlan show interfaces` 解析 SSID
- Android：`WifiManager` / `NetworkCapabilities`；无 SSID 权限时申请后重读

## 二、操控页

- 模式选择：连续 / 长距离 / 中距离 / 短距离 互斥
- 左侧 X/Y/Z/I/O 与右侧 关节/门型/直线 互斥（默认仅「关节」高亮）
- 点动 ±：`Listener` 保证鼠标移出后抬起仍停止连续点动

## 三、Android 适配

- `LpUniformAppViewport` 按 `viewPadding` / 手势 inset 留白
- 去掉 `windowFullscreen`；编程页 Android 包 `SafeArea`
