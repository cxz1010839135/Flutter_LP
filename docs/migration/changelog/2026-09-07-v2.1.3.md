# 2026-09-07 变更详情（2.1.3）

## 背景

编程页功能区与代码区连成一整块白底，分类按钮缝里还会漏出白框。备份恢复时每条小文件都先删再 chmod，现场经常卡很久。

## 一、Blockly 编程页

- 功能区与代码区视觉分离，中间露出页面底色；「领鹏智能编程」顶栏不改
- 功能区不再铺整列白底，切图按钮对齐槽位，避免白框伸进代码区

## 二、备份恢复 / 上传

- 小于 1MB 的文件直接覆盖，不再每条预删
- 仅动态库与主程序补执行权限，xml/txt 等跳过 chmod
- 小文件上传短等回包；驱控不关 socket 时读完 HTTP 应答即下一文件

## 三、版本与发布

`pubspec.yaml` → `2.1.3+1`

|------|------|
| Windows（推荐） | `dist/LPRobot-2.1.3-x64-Setup.exe` |
| Windows MSI | `dist/LPRobot-2.1.3-x64.msi` |
| Android | `dist/LPRobot-2.1.3.apk` |
