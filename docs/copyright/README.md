# 软件著作权登记材料

本目录包含「领鹏智能机器人上位机软件 V2.0.5」著作权登记所需文档，可直接打印或转 PDF 后提交中国版权保护中心（CPCC）。

> 本版登记材料描述连接、主页、可视化编程（常规编辑/保存/下发）、操控、监控（含寄存器监视）、参数配置等业务功能；**不含**智能对话辅助生成可视化程序等扩展能力。说明书正文避免出现 Cursor 等第三方编程工具名称。

## 文件清单

| 文件 | 用途 |

## 推荐生成顺序

在工程根目录依次执行：

```powershell
# 1) 源程序鉴别材料
dart run tool/generate_copyright_source.dart

# 2) 登记信息表 + 源程序 Word（不含带图说明书）
python tool/generate_copyright_word.py --skip-manual

# 3) 带界面截图的软件说明书（原稿 + V2.0.5 现场截图）
python tool/generate_copyright_manual_with_shots.py
```

页眉为「领鹏智能机器人上位机软件 V2.0.5」。著作权人、公司名称、开发完成日期等字段已标注 **（待填写）**。

## 重新生成源程序

版本号或源码变更后：

```powershell
dart run tool/generate_copyright_source.dart
```

生成脚本默认排除 `lib/blockly/ai/` 等未纳入本版登记范围的扩展源码。

## 提交前检查

1. 在 Word 中搜索「待填写」，补全：著作权人、公司名称、开发完成日期、联系人等。
2. 确认说明书已含连接/主页/操控/点位/文件/驱动，以及可视化编程（逻辑/变量/运动/自定义/搜索）界面图，且全文无 Cursor 字样。若原 `软件说明书.docx` 被占用，会另存为 `软件说明书_V2.0.5.docx`。
3. 导出为 PDF 后上传 CPCC；源程序 docx 确认每页 ≥50 行（等宽字体）。
4. 登录 https://register.ccopyright.com.cn 在线填表并上传 PDF。
