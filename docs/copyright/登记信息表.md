## 三、功能与技术特点（摘要，可直接粘贴到申请表）

**主要功能：**

本软件是一套面向领鹏系列工业机器人的上位机编程、调试、监控与运行管理系统，主要服务于自动化设备集成、机器人现场调试、生产程序维护及日常运维。软件通过以太网与机器人控制器建立连接，可识别设备状态并完成连接、断开、异常提示和通信状态展示，首页集中显示机器人型号、运行模式、使能状态、当前位置、报警信息及输入输出状态，便于操作人员快速掌握设备工况。操控功能支持关节坐标、直角坐标等方式下的单轴点动、连续运动、速度调整、回零、停止及相关操作，并设置必要的状态校验和操作提示，降低误操作风险。点位管理功能可读取、编辑、保存和调用机器人点位数据，支持对点位名称、坐标值及相关参数进行维护，为搬运、取放、码垛等工艺程序提供基础数据。可视化编程功能采用图形化功能块组织程序逻辑，提供逻辑判断、变量运算、运动控制和自定义功能分类，用户可通过拖放、组合、复制、删除及搜索定位等方式编辑流程，并完成工程的新建、打开、保存、校验、下发和运行，减少直接编写代码的学习成本。程序运行过程中可查看当前执行状态、主要变量及异常信息，并能够执行启动、暂停、停止等控制操作。监控功能可实时读取机器人位姿、数字输入输出及PLC寄存器数据，支持D、M、S、X、Y等类型寄存器的批量添加、地址配置、别名设置、状态刷新和持久化保存，方便排查现场信号及联动逻辑。参数配置功能用于维护驱动器参数、地址参数、机器人型号及运动相关配置；文件管理功能支持程序文件、配置文件和功能库的浏览、保存、备份及恢复，便于工程迁移和版本留存。软件对通信异常、初始化失败、控制器报警及文件读写错误提供可视化提示，并对关键操作进行确认，提高系统使用的稳定性。系统采用统一界面布局，支持Windows桌面端和Android横屏设备运行，可适配不同分辨率的工业电脑与触控终端，适用于工业机器人安装调试、程序编制、生产运行监视、故障诊断和设备维护等场景。

**技术特点：**

1. 采用 Flutter 跨平台框架，业务逻辑以纯 Dart 实现，Windows/Android 共用同一套代码基线。
2. 基于 HTTP/JSON 与机器人控制器通信，内网明文协议，连接标识为 `LPZN V{version}`。
3. 可视化编程通过本地静态资源与 WebView 桥接实现，支持工程保存至 `config/server`、`files/projects`、`files/funlib`，并支持积木搜索定位。
4. 200ms 周期轮询位姿、IO、报警等遥测数据，主界面实时刷新；监控页支持 D/M/S/X/Y 寄存器监视，上限可配置并持久化。
5. Windows 发布为 MSI 安装包（领鹏智能.exe），安装至 Program Files 时用户数据自动迁移至 `%LOCALAPPDATA%\Lingpeng\LPRobot\`，无需管理员权限。

> 本登记版本功能范围不含智能对话辅助生成可视化程序等扩展能力。

## 七、登记流程简述

1. 登录 [中国版权保护中心](https://register.ccopyright.com.cn) 注册账号。
2. 选择「计算机软件著作权登记」→ 填写申请表（参照上文）。
3. 上传 PDF：软件说明书、源程序前 30 页 + 后 30 页（合并或分文件，按系统要求）。
4. 邮寄或在线提交鉴别材料（以当前 CPCC 政策为准）。
5. 缴费（官费约 300 元/件，加急另计）。
6. 审查周期约 30～60 个工作日（普通），通过后领取登记证书。
